Credits
=======

Dynamic Sword Skills was originally created by **coolAlias**.
This is an unofficial Minecraft 1.7.10 rebuild maintained by **lkust**.

Original project
----------------
* coolAlias - original author of Dynamic Sword Skills
* Repository: https://github.com/coolAlias/DynamicSwordSkills (branch `1.7.10`)
* CurseForge: https://www.curseforge.com/minecraft/mc-mods/dynamic-sword-skills

Source base
-----------
This rebuild is based on the `1.7.10` branch of the repository above.

⚠️ That branch is **not identical** to the final Minecraft 1.7.10 version the
original author published on CurseForge on 2017-10-30. It received further
commits afterwards (the last one dated 2020-05-02), and the two differ in
structure - for example, the 2017 CurseForge build ships 87 classes and still
carries an incorrect `zeldaswordskills` entry in its `mcmod.info` dependencies
(the mod has no required dependencies of its own - its content was split off
from Zelda Sword Skills, but that mod does not need to be installed), while this
source base contains 112 source files and no such entry.
