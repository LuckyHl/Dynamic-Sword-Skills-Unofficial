# Dynamic Sword Skills（非官方 1.7.10 版）

[English](README.md) | **简体中文**

基于 coolAlias 的 **Dynamic Sword Skills** 重建的非官方版本，面向
**Minecraft 1.7.10 + Forge 10.13.4.1614**。

本模组适合那些只想要 ZSS 的战斗技能、不想要其中的怪物、物品、世界生成等内容的玩家。

此外还有"技能物品"，即使玩家尚未学会对应技能，也能通过它使用该技能 —— 这些物品散布在世界各处。

## 上游来源

本次重建基于原作者仓库的 **`1.7.10` 分支**：

- 仓库：https://github.com/coolAlias/DynamicSwordSkills
- 分支：https://github.com/coolAlias/DynamicSwordSkills/tree/1.7.10
- 原作者：coolAlias

**⚠️ 本项目使用的源码，与原作者于 2017-10-30 在 CurseForge 发布的 Minecraft 1.7.10 最终版并不相同。**

GitHub 的 `1.7.10` 分支在那次 CurseForge 发布之后仍在继续提交（最后一次提交日期为
2020-05-02），两者是**不同的代码基线**，而不是"同一版本加了几个修复"。举例来说：
CurseForge 的 2017 版只含 87 个 class，且其 `mcmod.info` 里仍残留一条
`zeldaswordskills` 依赖声明 —— 该声明是**错误的**，本模组**没有任何必需的前置**
（它的内容虽源自 Zelda Sword Skills 的拆分，但并不需要安装那个模组）；而本项目
所用的分支包含 112 个源文件，且没有该声明。

CurseForge 页面：https://www.curseforge.com/minecraft/mc-mods/dynamic-sword-skills

## 改动清单

**修改日期：2026-09-29**（GPLv3 §5(a) 所要求的"相关日期"）

以下列出本版本相对上游源码的全部差异。**标注（默认开启）的条目在装好模组后立即改变游戏行为**；
其余条目默认关闭、可配置，或对游戏行为没有影响。

### 新增

**配置项** —— `general` 分类下新增 17 项，全部支持服务端到客户端的网络同步：

| 配置项 | 默认 | 作用 |
|---|---|---|
| `wideSwordBeamHitbox` | **开启** | 剑气判定宽度与视觉宽度一致 |
| `swordBeamAnywhere` | **开启** | 剑气不再要求站在地面 |
| `swordBeamNoCooldown` | **开启** | 剑气使用之间没有冷却 |
| `swordBeamIgnoreWaterDrag` | **开启** | 剑气在水中不受阻力 |
| `swordBeamSpeedMultiplier` | 1.0 | 剑气飞行速度倍率 |
| `swordBeamNoRangeLimit` | 关闭 | 移除剑气的寿命上限 |
| `leapingBlowNoAttackRequired` | **开启** | 跳劈无需按攻击键 |
| `armorBreakBonusDamage` | **开启** | 破甲造成额外伤害（另有 4 项数值配置）|
| `dashSpeedDamageBonus` | **开启** | 突刺伤害随移动速度提升（另有 4 项数值配置）|

**技能改动**（以下全部默认开启）

- **剑气** —— 判定宽度加宽至与剑气视觉宽度一致，复用原版 `calculateIntercept` 路径，
  而非自研算法。
- **破甲** —— 造成随等级提升的额外伤害，取"每级固定值"与"每级攻击伤害百分比"中的较大者。
  百分比使它在高伤害模组武器下依然有意义，而固定值在那时几乎可以忽略。会额外消耗疲劳。
- **突刺** —— 伤害随移动速度（迅捷效果）提升，且现在计入武器伤害与附魔加成。会额外消耗疲劳。

**按键绑定** —— 从原作者 2017 年 CurseForge 发布版回移植：

| 按键 | 作用 |
|---|---|
| `V` | 切换连击 HUD 显示 |
| `~` | 切换自动锁定（潜行时为切换"是否锁定玩家"）|

### 修复

- **破甲** —— 格挡（按住右键）时按攻击键，技能无法释放。
- **突刺** —— 偶尔完整播放音效与后撤动画，却不造成任何伤害。该问题由 2020 版源码引入，
  2017 版不存在。
- **剑气** —— 技能等级应用后从未重算飞行速度，导致 5 级剑气的射程与 1 级相同（约 18 格）。
  修复后 5 级约 30 格。**该修复不受任何配置项控制。**
- **切换维度后技能全部失效** —— 按键状态丢失。
- **从末地返回后技能全部失效** —— 玩家技能数据绑定在被移除的实体上。
- 从 2017 版回移植的自动锁定切换不会保存设置；现在可以持久保存。
- 移除了失效的 VersionChecker 链接。
- 移除了 `mcmod.info` 中错误的 `zeldaswordskills` 依赖声明。本模组没有任何必需前置。

### 变更

- `zh_CN.lang` 全量重写 —— 上游文件不完整。
- 原版中针对 Battlegear2 的**可选联动**已被完全移除，源码中不再引用 Battlegear2 API。
  需要说明的是：**原版在运行时也并不要求安装 Battlegear2** —— 该联动是可选的，
  未安装时会自动跳过。
- 使用 GTNH / RetroFuturaGradle 工具链构建。

### 未修改

- 技能成长、技能球掉率与战利品行为均保持上游默认值。
- mod id 保持不变（`dynamicswordskills`），老存档可以继续使用。

## 基本操作

本模组几乎完全沿用原版操作方式。

部分技能（例如回旋斩）需要同时按下多个移动键；**手柄**玩家可能需要在配置中开启
**Additional Controls**，它会添加一组等同于 WASD 的按键绑定，可映射到手柄的其他按键上。
请注意，这些按键实际上并不能用于移动。

### 自定义按键
- `x` —— 激活或取消锁定类技能
- `tab` —— 在锁定状态下切换到下一个目标
- `p` —— 打开技能界面
- `v` —— 切换连击 HUD 显示
- `~` —— 切换自动锁定（潜行时为切换"是否锁定玩家"）

### 可选附加控制
- 上方向键 —— 等同于原版 `W`
- 下方向键 —— 等同于原版 `S`
- 左方向键 —— 等同于原版 `A`
- 右方向键 —— 等同于原版 `D`

## 命令

`/grantskill <skill | all> <player> <level>`
将某个技能或全部技能以指定等级授予目标玩家

- 省略 `<level>` 时，改为将技能等级提升 1 级
- 省略 `<player>` 时，目标为命令发送者

`/removeskill <skill | all> <player>`
移除目标玩家的某个技能或全部技能的所有等级

- 省略 `<player>` 时，目标为命令发送者

## 技能

技能通过"技能球"学习。技能球会视服务器配置，偶尔从各类生物身上掉落，或在箱子中找到。

部分生物会绑定特定的技能球，此时它们总会尝试掉落 —— 通常是其指定技能球，
但根据配置也可能随机。未绑定特定技能球的生物可能尝试掉落随机技能球，但即使掉率设为
100%，也只是"尝试掉落"，并不保证一定掉出。

生物尝试掉落技能球时，基础掉率范围为 0%~10%（默认全部为 5%）；使用带有**抢夺**
附魔的武器可显著提高掉率。

学会技能后，打开游戏内的技能界面（默认按键为 `p`），点击技能球即可查看其效果
说明与激活方式。

## 构建

本仓库不包含 Gradle wrapper 的 jar 文件（所有 `*.jar` 均被 `.gitignore` 排除）。
构建前先生成一次 wrapper：

    gradle wrapper

之后照常构建：

    ./gradlew build          # Linux / macOS
    gradlew.bat build        # Windows
